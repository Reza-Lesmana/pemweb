# Tugas 2 - Mengenal HTML

Website bertema ITERA untuk tugas Pengembangan Aplikasi Web.

## Struktur
- `index.html` : halaman utama
- `berita.html` : halaman berita dengan elemen `article`
- `profil.html` : halaman profil
- `assets/logo-itera.svg` : logo lokal

## Ketentuan yang dipenuhi
- Struktur semantik: `header`, `nav`, `main`, `article`, `section`, `aside`, `footer`
- Heading terstruktur
- Minimal satu tabel
- Link antarhalaman berfungsi
- Tidak menggunakan CSS, sesuai catatan tugas
- Menggunakan `alt` pada gambar
- Menggunakan elemen HTML semantik untuk struktur konten

## Validasi
Validasi setiap file HTML melalui W3C Markup Validation Service:
https://validator.w3.org/

Setelah valid, ambil screenshot hasil validasi untuk dilampirkan pada pengumpulan.
